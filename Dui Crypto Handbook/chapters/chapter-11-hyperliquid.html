Chapter 11 • Architecture

HyperCore, HyperBFT & HyperEVM

Hyperliquid
Architecture

สร้าง L1 เองทั้งหมด — เพราะไม่มี chain ไหนเร็วพอ

Hyperliquid ไม่ได้ deploy บน Ethereum, Solana หรือ Cosmos แต่สร้าง blockchain ของตัวเองตั้งแต่ consensus ไปจนถึง EVM เพื่อควบคุม latency ให้ต่ำที่สุดสำหรับ trading โดยเฉพาะ

User

Trading Interface + Session Keys + Builder Codes

Web app, API, third-party front-end ผ่าน Builder Codes — Session keys อนุญาตให้ pre-sign trading session ทำให้ทำ one-click trade ได้โดยไม่ต้อง confirm ทุก order ใน wallet Phantom, Rabby, MetaMask integrate แล้ว รวม Builder Code volume เกิน $100B

HyperEVM

EVM-Compatible Smart Contracts (Dual-Block)

Solidity contracts บน EVM ที่ share consensus กับ HyperCore — fast block ทุก 1 วินาที (2M gas) สำหรับ lightweight ops, slow block ทุก ~1 นาที (30M gas) สำหรับ complex contracts EVM contracts อ่าน perp positions, spot balances, staking data จาก HyperCore ได้โดยตรง

HyperCore

On-chain CLOB — ~200K orders/sec

Central Limit Order Book fully on-chain ทุก bid/ask/cancel บันทึกบน chain จริง รองรับ native perps, HIP-3 deployer perps, spot markets USDC จาก Arbitrum ~$6B เป็น main collateral Circle ประกาศ native USDC บน HyperEVM ก.ย. 2025

HyperBFT

Byzantine Fault Tolerant Consensus — finality 0.2s

Optimize สำหรับ trading workload — ทำงานได้ตราบที่ >⅔ ของ validators honest ใช้ deterministic leader schedule ทุก ~90 นาที (100,000 rounds) Validators ต้อง self-delegate ≥10,000 HYPE

Asset Linking: HyperCore spot asset แต่ละตัว link กับ ERC-20 บน HyperEVM ผ่าน bridge contract ที่ 0x200... address เดียวกัน USDC หรือ HYPE ไหลระหว่าง Core trading กับ EVM DeFi ได้โดยตรง — ไม่ต้อง wrap ไม่ต้อง bridge แยก BTC, ETH, SOL bridge ผ่าน Unit guardian network (2-of-3 quorum: Unit + Hyperliquid + Infinite Field)

Chapter 11 • Products & HLP

Products, HLP และบทเรียนจากวิกฤติ

Hyperliquid
Products

3 Product หลักบน On-chain CLOB เดียวกัน

Perps, Hyperps (pre-launch), และ Spot trading ทั้งหมดแชร์ order book และ liquidity เดียวกัน ขับเคลื่อนโดย HLP — community-owned vault ที่ทำหน้าที่ market maker และ liquidator พร้อมกัน

3 Product Types

Perps · Hyperps · Spot

  • Perps — perpetual futures มาตรฐาน 150+ สินทรัพย์ leverage สูงสุด 50x funding rate ทุก 8 ชั่วโมง listing แบบ permissionless ผ่าน HIP-3 (ต้อง stake 500K HYPE)
  • Hyperps — pre-launch perps สำหรับ token ที่ยังไม่มี reliable price feed ใช้ internal pricing แทน external oracle เหมาะกับ speculation หรือ hedge farmed tokens
  • Spot — ซื้อขาย token จริงบน CLOB listing ผ่าน Dutch auction (HIP-1) BTC, ETH, SOL bridge มาเป็น HIP-1 token ผ่าน Unit guardian network
HLP — Hyperliquidity Provider

Community-Owned Market Maker & Liquidation Backstop

ผู้ใช้ฝาก USDC เข้า HLP vault รับส่วนแบ่ง PnL — HLP แบ่งเป็น child vaults ที่ isolated risk limit ป้องกัน contagion เมื่อตลาด stress ในช่วง October 2025 cascade ($20B+ liquidated) HLP process ครึ่งหนึ่งของ liquidations ทั้งหมด กำไรได้กว่า $40M ใน 1 วัน (~10% daily return) platform ไม่มี bad debt HLP คิดเป็นเพียง ~1–2% ของ daily volume ปัจจุบัน เนื่องจาก organic market makers เข้ามามากขึ้น

Hyperliquid
HIP-3 / RWA

เปิดให้ทุกคน Deploy DEX บน Hyperliquid

HIP-3 เปิดตัว 13 ต.ค. 2025 — ใครก็ build perpetual DEX บน HyperCore ได้ โดย stake 500K HYPE (~$16–25M) แลกกับ access ถึง order book, liquidity และ fee sharing 50/50 กับ protocol

HIP-3 Mechanicsเปิดตัว 13 ต.ค. 2025

กฎของ HIP-3

  • Stake: 500,000 HYPE ล็อค 30 วันแม้หลัง halt — slash ได้สูงสุด 100% หาก downtime นาน
  • Free listings: 3 markets แรกฟรี ถัดไปใช้ Dutch auction ทุก 31 ชั่วโมง ราคา floor 500 HYPE
  • Fee split: Taker fee ~0.045% แบ่ง 50% ให้ deployer / 50% ให้ protocol (2x เพื่อ maintain protocol revenue)
  • Growth Mode (19 พ.ย. 2025): Fee ลดลง 90%+ สำหรับ market ใหม่ — ต่ำสุดถึง 0.00144% เพื่อ bootstrap volume

HIP-4 Outcome Markets ประกาศ 2 ก.พ. 2026 · Testnet มี.ค. 2026

Prediction Markets & Bounded Options บน HyperCore

HIP-4 นำ outcome markets มาสู่ HyperCore โดยตรง — ต่างจาก Polymarket ที่เป็น isolated platform ทุก outcome contract share margin system กับ perp positions ได้ทันที HYPE ขึ้น 10% ใน 24 ชั่วโมงหลังประกาศ

Binary Prediction Markets

คำถาม Yes/No แต่ละคำตอบ settle เป็น 1 USDH (ถูก) หรือ 0 USDH (ผิด) ราคา token สะท้อน implied probability โดยตรง เริ่มด้วย BTC และ HYPE 1-day expiry บน testnet

Bounded Options-like Contracts

Fully collateralized — ไม่มี margin call ไม่มี liquidation ผู้ซื้อเสียได้แค่ capital ตั้งต้น เปิดด้วย 15-minute call auction ก่อน order book trading ป้องกัน price manipulation ช่วงเปิดตลาด

Collateral: USDH (native stablecoin ของ Hyperliquid) · Mainnet: ยังไม่ประกาศวันแน่นอน คาดภายใน 2026

ความเร็วมาพร้อมกับ Centralization

Hyper Foundation ควบคุม ~80% ของ staked HYPE ผ่าน validators ของตัวเอง — ทำให้ทางทฤษฎีสามารถ halt chain ได้ node software ยังปิด source ทำให้ validator "blind sign" binary โดยไม่รู้ว่า code ทำอะไร ใน ก.ค. 2025 API traffic spike ทำให้ trading หยุด 37 นาที แม้ blockchain ยังผลิต block ต่อเนื่อง Hyperliquid ยืนยันมีแผน open-source และ decentralize infrastructure ตามเวลา
