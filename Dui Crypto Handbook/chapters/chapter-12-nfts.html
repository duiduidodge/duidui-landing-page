Chapter 12 • Foundations

NFT คืออะไร — Digital Ownership ที่แท้จริง

NFTs
Overview

ปัญหาที่ NFT มาแก้

ก่อน NFT โลกดิจิทัลมีปัญหาพื้นฐาน: ทุกอย่าง copy ได้สมบูรณ์แบบในต้นทุนศูนย์ ไม่มีทางพิสูจน์ว่า "ต้นฉบับ" คืออะไร NFT แก้ปัญหานี้โดยการแยกความเป็นเจ้าของออกเป็นชั้น ๆ ที่บันทึกบน blockchain อย่างถาวร

ในเดือนมีนาคม 2021 ศิลปิน Beeple ขายงานชื่อ "Everydays: The First 5000 Days" ผ่าน Christie's ด้วยราคา $69.3 ล้าน ผู้ซื้อที่รู้จักในชื่อ Metakovan ไม่ได้ซื้อสิทธิ์พิเศษในการดูภาพ ใครก็ตาม right-click save ได้ฟรีและได้ไฟล์ที่เหมือนกันทุกพิกเซล สิ่งที่เขาซื้อคือ proof of ownership ที่ verify ได้ด้วย cryptography บน Ethereum blockchain — บันทึกถาวรที่ทุกคนตรวจสอบได้ว่า wallet ของเขาคือเจ้าของ "ต้นฉบับ" นี้

นี่คือหัวใจของ NFT (Non-Fungible Token — โทเคนที่ไม่สามารถแทนกันได้): ต่างจาก ERC-20 token อย่าง ETH หรือ USDC ที่ทุกหน่วยเท่ากันทุกประการ NFT แต่ละ token มี identifier เฉพาะ ที่ไม่ซ้ำกันภายใน smart contract ของมัน combination ของ contract address + token ID จึงเป็น globally unique ทั่วทั้ง blockchain

Token Control

Blockchain Ownership Record

Immutable ledger บันทึกว่า wallet ใดถือ token ID ใด — ใครก็ verify ได้ ไม่มีใครเปลี่ยนแปลงได้ นี่คือสิ่งที่อยู่ "on-chain" อย่างแท้จริง

Provenance

Certificate of Authenticity จาก Creator

บันทึกที่พิสูจน์ว่า token นี้ถูก mint จาก wallet ของ creator จริง — สร้างสายการพิสูจน์ความแท้จากต้นทางถึงเจ้าของปัจจุบัน

Usage Rights

License สำหรับ Content ที่แนบมา

กำหนดว่าเจ้าของทำอะไรกับ content ได้บ้าง — บางโปรเจกต์ให้ commercial rights (BAYC), บางโปรเจกต์เปิด public domain (CC0 เช่น Nouns DAO)

Utility

Smart Contract Permissions & Token-Gating

Smart contracts ตรวจสอบ token possession แล้วให้สิทธิ์เข้าถึง — community access, event entry, in-game perks, governance rights, หรือใดก็ได้ที่ developer เขียนไว้

ชั้นเหล่านี้ทำงาน modular และ independent กัน — owner อาจถือ token บน Ethereum ขณะที่ภาพอยู่บน IPFS license บอกว่าใช้ commercial ได้ และ smart contract อีกตัวให้สิทธิ์เข้า private Discord โดยอัตโนมัติ ความยืดหยุ่นนี้เปิดประตูสู่กรณีใช้งานที่ไม่มีใน analog world: NFT ที่ evolve ได้, NFT ที่มี wallet ของตัวเอง, credentials ที่ไม่สามารถโอนได้

Copyright Reality: การถือ NFT ไม่ได้แปลว่าได้ copyright อัตโนมัติ — ภาพยังคง copy ได้ฟรี usage rights กำหนดโดย license แยกต่างหากซึ่งมักอยู่ off-chain และ enforce ยากข้ามเขตอำนาจศาล Bored Ape Yacht Club ให้ commercial rights แต่ยัง retain IP control ขณะที่ Nouns DAO และ CrypToadz ใช้ CC0 — "no rights reserved" — เพื่อให้ทุกคน remix และต่อยอดได้อย่างเสรี

Storage, Token Types และ Supply Mechanics

NFTs
Infrastructure

ปัญหา: ถ้า server ปิด NFT หายไปด้วยไหม?

การ mint NFT บังคับให้ตัดสินใจ: เก็บทุกอย่าง on-chain ได้ความถาวรสูงสุดแต่ค่า gas แพงมาก หรือเก็บ content off-chain ถูกกว่าแต่เสี่ยง dead link ในอนาคต

Centralized Server
HIGH RISK

Metadata/ภาพอยู่บน server ของ project team — ถูกที่สุด ยืดหยุ่นที่สุด แต่ถ้า project หยุดดำเนิน server ปิด หรือโดน hack ภาพ NFT หายหมด

⚠ "Rug" storage risk สูง
IPFS
MEDIUM

Content-addressed storage — ไฟล์ระบุด้วย hash ของเนื้อหาเอง เปลี่ยนไฟล์ไม่ได้ลักษณะนี้ แต่ต้องมีคนช่วย "pin" ไว้ ถ้าไม่มี node pin ไฟล์หายได้

ต้องการ ongoing pinning service
Arweave
PERMANENT

จ่ายครั้งเดียวเพื่อ permanent storage ผ่าน endowment model เรียกว่า "permaweb" — ค่าใช้จ่ายสูงกว่า IPFS แต่ไม่ต้องกังวลเรื่อง ongoing maintenance

Pay-once, store forever
Fully On-Chain
MAXIMUM

ทุกอย่างอยู่บน blockchain โดยตรง — เช่น Autoglyphs (Larva Labs) หรือ Nouns DAO SVG on-chain ความถาวรสูงสุด censorship resistant แต่ค่า gas สูงมาก ($1,000+ ต่อ image)

True permanence, expensive

Best practice คือ layered approach: ใช้ content-addressed URIs (IPFS/Arweave hashes) เพื่อป้องกันการเปลี่ยนไฟล์แบบเงียบ ๆ เก็บ critical provenance data on-chain และมี multiple pinning providers เป็น backup

Advanced Token Types: มากกว่าแค่ภาพ

Concept

Token Type Spectrum

  • Dynamic NFTs — evolve ตามข้อมูลจริง: sports card update stats หลังเกม, digital art เปลี่ยนสีตามสภาพอากาศ, game character level up
  • Composable NFTs — token ที่มี token อื่นอยู่ข้างใน: ที่ดินเสมือน (NFT) → บ้าน (NFT) → เฟอร์นิเจอร์ (NFT) ขายที่ดินโอนทุกอย่างพร้อมกัน
  • Semi-fungible (ERC-1155) — ตั๋วคอนเสิร์ตเริ่มเหมือนกัน (fungible) แต่หลังใช้งานบันทึก seat และ event เฉพาะตัว (unique)
  • Soulbound Tokens (SBTs) — โอนไม่ได้โดยออกแบบ: ปริญญา, certification, achievement, reputation ที่ผูกกับบุคคลถาวร

Chapter 12 • Standards

ERC-721, ERC-1155 และ NFT Categories

NFTs
Standards

Rulebook ที่ทำให้ NFT ทำงานได้ทั่วทั้ง Ethereum

Standard คือชุดฟังก์ชันขั้นต่ำที่ contract ต้อง implement — ทำให้ marketplace, wallet, และ game ทำงานกับ NFT ทุก collection ได้โดยไม่ต้องเขียน code ใหม่ทุกครั้ง

ERC-721

Core Functions ที่ทุก NFT Contract ต้องมี

ownerOf(tokenId) → ถาม: "ใครถือ NFT #1234?"
transferFrom(from, to, tokenId) → โอน NFT #1234 จาก Alice ไป Bob
approve(to, tokenId) → Alice ให้ Bob โอน NFT ตัวเดียวได้
setApprovalForAll(operator, approved) → ⚠ Alice ให้ marketplace โอน NFT ทุกตัวได้

Extension ที่สำคัญ: tokenURI(tokenId) ส่งคืน URL ไปยัง JSON metadata ที่มีชื่อ, คำอธิบาย, ภาพ, และ attributes

ERC-721 vs ERC-1155

เลือก standard ตาม use case — ไม่มีตัวไหน "ดีกว่า" ในทุกสถานการณ์

FeatureERC-721ERC-1155
Token Type Unique เท่านั้น (1 token = 1 item) Fungible + Non-fungible ในที่เดียว
Batch Transfer ไม่รองรับ (1 tx = 1 token) รองรับ (1 tx = หลาย token, gas ถูกกว่า)
ใช้งานหลัก Art, PFPs, collectibles Games, gaming assets, ticket systems
Gas Efficiency ปกติ สูงกว่า (batch ops)
Contract Complexity ง่ายกว่า ซับซ้อนกว่า
Semi-fungible ไม่รองรับ native รองรับ (ตั๋ว → used)

Chapter 12 • Security

Scams, Wallet Drainers และ Launch Strategies

NFTs
Security

NFT Space มี Attack Surface ที่กว้างมาก

ฟังก์ชัน approval ใน ERC-721/1155 มีอำนาจสูงมาก — เมื่อ grant แล้ว blockchain ไม่มีวันย้อนกลับ scammer ออกแบบทุกกลยุทธ์เพื่อให้คุณ sign โดยไม่รู้ตัว

🎣 Phishing via Fake Sites

สร้าง replica ของ official website หรือส่งลิงก์ผ่าน Discord/X ให้ connect wallet สำหรับ "free mint" หรือ "exclusive airdrop" — site หน้าตาเหมือนจริงทุกอย่างแต่ domain ต่างกันเล็กน้อย

Always verify URL ด้วยตา — ไม่ใช่แค่ชื่อ

💀 Wallet Drainers

ให้คุณ sign transaction ที่ดูเหมือน signature request ธรรมดา แต่จริง ๆ คือ malicious payload ที่ grant setApprovalForAll ให้ attacker — drain NFT + token ทั้ง wallet ในวินาทีเดียว

Signature ≠ Safe — อ่าน what you sign ทุกครั้ง

🖼 Fake Collection Listings

สร้าง contract ชื่อเหมือนกับ collection ดังแต่ address ต่าง ขาย NFT ในราคาถูกกว่า floor — ผู้ซื้อได้ NFT ปลอมที่ไม่มีมูลค่า สังเกต verified checkmark และ contract address

ตรวจสอบ contract address เสมอ

💸 Discord DM Scams

แอบอ้างเป็น moderator หรือ team member ส่ง DM แจ้ง "คุณได้รับ whitelist พิเศษ" พร้อมลิงก์ไป malicious site — team จริงไม่ DM ก่อนเกือบทุกกรณี

Official team ไม่ DM ก่อน — ไม่เชื่อ unsolicited DM
Best Practice Self-Custody Safety

วิธีป้องกันตัวใน NFT Space

  • ใช้ hardware wallet (Ledger, Trezor) สำหรับ high-value NFT — private key ไม่เคยออกจากอุปกรณ์
  • เตรียม "burner" wallet แยกสำหรับ mint project ใหม่ — ไม่เก็บ asset มีค่าไว้ใน wallet นั้น
  • Revoke approvals ที่ไม่จำเป็นผ่าน revoke.cash หรือ Etherscan token approvals
  • ใช้ wallet simulation tools เช่น Pocket Universe, Fire ที่แสดงผลลัพธ์ของ transaction ก่อน sign

Launch Strategies: วิธีกระจาย NFT อย่างยุติธรรม

Fair Launch

ราคาเดียว first-come-first-served — ง่ายแต่โดน bot ครองสูง เหมาะเมื่อต้องการ decentralized distribution สูงสุด

Dutch Auction

เริ่มราคาสูงลดลงตามเวลาจนถึง demand — bot-resistant มากกว่า ราคา clear ที่จุด market price จริง

Allowlist (Whitelist)

approve wallet ที่ active community กก่อน public sale — ให้รางวัล engagement จริง ลด gas war

Bonding Curve Mint

ราคาเพิ่มขึ้นตามจำนวน mint — Nouns DAO ใช้ (1 NFT/วัน ราคาจาก auction) early minter ได้ราคาดีกว่า

NFTs
Solana

Solana พัฒนา NFT ecosystem แยกจาก Ethereum โดยสิ้นเชิง

ค่า fee ต่ำ, throughput สูง, และ architecture ที่ต่างออกไป ทำให้ Solana สร้าง standards, tooling, และ culture ที่เป็นเอกลักษณ์ของตัวเอง

Marketplaces

Magic Eden & Tensor — แบ่ง Segment ชัดเจน

Magic Eden ครอง early volume ด้วย UX ง่ายและ launch tools สำหรับ creator — Tensor เกิดทีหลังเจาะกลุ่ม professional trader ด้วย trait-based bidding, automated pricing pools, และ advanced portfolio views ต่างจาก Ethereum ที่ OpenSea นานครอง Solana มี two-tier market structure ชัดเจนตามประเภทผู้ใช้

Metaplex

Foundation Protocol — Metadata, Collections, Royalties

Framework มาตรฐานสำหรับ NFT บน Solana ครอบคลุม metadata schema, collection verification, royalty configuration, และ token standards ส่วนใหญ่ของ Solana NFT ecosystem สร้างบน Metaplex ทำให้เป็น single point of standardization ที่คล้ายกับบทบาทของ OpenZeppelin บน Ethereum

cNFTs

Compressed NFTs — นวัตกรรมที่ไม่มีบน Ethereum

State compression เก็บ cryptographic summary on-chain และ detailed data off-chain ลดต้นทุน mint จาก ~$0.024 เหลือ <$0.001 ต่อ NFT — unlock use cases ที่ Ethereum ทำไม่ได้: large-scale airdrop ล้านชิ้น, loyalty programs, gaming assets จำนวนมหาศาล

Royalty Wars บน Solana: เหมือน Ethereum, marketplace competition ผลักดัน creator royalties ไปสู่ optional standard บาง NFT standards พยายาม enforce royalties ที่ contract level แต่การ enforce ยังขึ้นอยู่กับ marketplace cooperation อยู่ดี Tensor และ Magic Eden ต่างเคยเปลี่ยนนโยบาย royalty ตามแรงกดดัน competitive หลายครั้ง

Markets

OpenSea vs Blur — การต่อสู้ที่เปลี่ยน NFT Market Structure

NFT marketplaces วิวัฒน์จาก listing site ธรรมดาไปสู่ financial infrastructure ที่ซับซ้อน — core vulnerability คือ royalty ไม่ได้ build ใน ERC-721/1155 ทำให้ marketplace ใช้เป็นอาวุธแข่งขัน

Nov 2022
Blur เปิดตัว — ชนะ Professional Traders ทันที
ออกแบบสำหรับ trader มืออาชีพ: advanced portfolio management, real-time pricing, trait-based filtering + royalties optional (0.5% minimum) + BLUR token rewards สำหรับ trading volume
Feb 2023
Blur แซง OpenSea ด้าน Trading Volume
OpenSea response ไม่สอดคล้อง — enforce full royalties เฉพาะ collection ใหม่ผ่าน Operator Filter แต่ enforce ไม่ได้บน collection เก่า trader ย้ายไป Blur เพราะ fee ต่ำกว่า
Aug 2023
OpenSea ยกเลิก Royalty Enforcement
แรงกดดัน competitive บังคับ OpenSea ทิ้ง royalty policy ที่ protect creator สัญญาณว่า volume ชนะ creator protection
2025
OpenSea กลับมา — Blur ถดถอย
Blur volume ส่วนใหญ่ driven by token incentives/airdrop farming ไม่ใช่ organic demand เมื่อ incentives หมด + NFT market collapse โดยรวม OpenSea reclaim dominant position บน Ethereum
ERC-2981 Royalty Standard: Standard ใหม่ที่ให้ contract "แนะนำ" จำนวน royalty ที่ควรจ่าย แต่ยังคงเป็น optional — marketplace ยังสามารถเลือก ignore ได้ ปัญหา structural ของ royalty enforcement ยังไม่ได้รับการแก้อย่างถาวร

Pricing Mechanics ที่ต้องเข้าใจ

Floor Price คือ NFT ที่ถูกที่สุดใน collection ณ ขณะนั้น — metric ที่ watch กันมากที่สุดแต่ misleading สุด Bored Ape ที่มี golden fur + laser eyes อาจขายได้ 10x เหนือ floor ขณะที่ common traits ขายที่ floor หรือต่ำกว่า trait rarity สำคัญมากกว่า floor ในหลายกรณี

Collection-Wide Bidding แก้ปัญหา illiquidity — แทนที่จะ bid NFT ตัวเดียว ผู้ซื้อ bid บน "Bored Ape ใดก็ได้ที่มี laser eyes" ทำให้ seller มี exit liquidity ง่ายขึ้น แต่ tradeoff คือ commoditize สิ่งที่ควรจะ unique

Key Takeaways

สรุปสิ่งที่ต้องจำจากบทนี้

  1. 01
    NFT แยก "ความเป็นเจ้าของ" ออกเป็น 4 ชั้นอิสระ

    Token control, provenance, usage rights, utility — แต่ละชั้นทำงาน modular และ programmable แยกกัน ภาพยังคง copyable ได้ฟรี

  2. 02
    ERC-721 = unique, ERC-1155 = multi-token + batch

    Standard กำหนด interoperability ทั่วทั้ง ecosystem — setApprovalForAll เป็น function ที่อันตรายที่สุดถ้า grant ให้ malicious contract

  3. 03
    Storage คือ risk ที่มองข้ามไม่ได้

    On-chain > Arweave > IPFS (pinned) > centralized server — ในแง่ permanence centralized storage มี "rug" risk ที่แท้จริง

  4. 04
    Solana compressed NFTs เปลี่ยน economics อย่างสิ้นเชิง

    <$0.001 ต่อ NFT ทำให้ large-scale airdrops, loyalty programs, gaming assets เป็นไปได้จริง — use case ที่ Ethereum ทำไม่ได้ในต้นทุนเดียวกัน

  5. 05
    Market หดตัวหนักจาก 2022 peak แต่ blue-chips ยังอยู่

    CryptoPunks และ Bored Apes retain cultural significance แม้ volume โดยรวมจะเป็น fraction ของ peak — NFT market mirrors traditional art: handful of established names hold value, long tail goes to zero
